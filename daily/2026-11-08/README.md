### N01 57张风格图在四个基座训练：分别选检查点与强度

**适用方向：画风LoRA·训练选型｜参考同一数据集在不同基座上的取舍与失败记录。**

**设计思路：风格集中与题材覆盖并看｜筛选统一视觉后，再检查近景、空场景和人物类型是否缺位。**

- 原作者与原文：[lepetitprince716355](https://civitai.com/articles/38060)。
- 原文：《One 57-Image Style Set on Four Bases: Anima, MOSS Image, Krea 2 and Qwen Image 2.1》，2026-11-08 00:08:35.460 +08:00发布；首次收录该方法文章，关联模型不因此重算新权重。
- 作者实践：143图筛成57图，同时改学习率，故不能把结果只归于减数据。严格筛风格也删掉近景等覆盖；作者用固定提示、seed和无LoRA对照行检查，保留男士、空场景、纯背景近景，避免只看训练loss。
- 检查点与强度：Anima选8/12 epoch，MOSS、Krea2选训练终点2000步，但未继续训练，不能归纳固定步数规律。第二套90年代赛璐璐风格在MOSS有效、Anima差异不明显；同基座的不同风格也可能需要不同强度。
- 条件差异：四路线rank／alpha32，但底模、学习率、caption格式与硬件不同；Anima在4060Ti，另外用128GB统一内存设备，计时统计范围也不同，不能据每步秒数排硬件效率。Krea训练Raw、预览Turbo，INT8适配记录自相矛盾，作者尚未复测。
- Qwen2.1分支：作者从1250续至2000步，在动漫提示上更显风格，但有写真场景仍未转；其ComfyUI试用16步CFG1出现结构破碎，24步CFG4／Euler/simple较完整，仍有杯子数量与发色错误。这是该LoRA／流程的作者经验，不是Qwen全家默认。
- 作者对Sabikaze文字定位为灰青基调、暖色点缀与松散墨线／干笔；本篇重点为设计与选型方法。本库没有看图，不将文字说明冒充视觉归纳；第二风格、Qwen候选与未测试项均保留原状态。
- 读取范围：文章正文全文；未看对照图、下载模型、读训练配置或复跑。

- 原文：《LoRA Studio ♡ A Training UI for sd-scripts》，2026-11-07 01:53:54.173 +08:00；近期首次补录。[原作者项目](https://github.com/cococolacake/lora-studio)是后续下载与反馈入口，本次未逐文件读取。
- 作者分享：以现有kohya-ss／sd-scripts为训练引擎，按脚本暴露参数，配简单与完整视图；可导入训练／数据TOML，管理队列、历史和保存状态续训。
- 可学习组织：数据浏览、caption编辑、去重与健康检查放在训练前；训练中看loss／进度和样本，按epoch×提示网格选检查点。元数据写入与发送到ComfyUI／SwarmUI是工具提供的操作入口，不是本库已执行。
