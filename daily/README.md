# 每日发现归档

本目录按北京时间日期保存每日广泛搜索的社区分享汇总。按日期和主题查找内容请使用[总索引](../每日检索可速查总结.md)。

## 目录约定

- 每次执行创建或更新 `daily/YYYY-MM-DD/`，当天主汇总为 `README.md`。
- 同日重跑和后续更正更新同一目录，保留日期和修改说明。
- 仅在需要时建立 `notes/` 保存较长的学习笔记，或 `workflows/` 保存可依原作者说明使用的小型公开配置；从当日汇总回链。
- 每条教程／分享在标题下给出“适用方向：短标签｜一句话用途”，当天速查表和总索引保留同样标注，便于浏览时判断方向；依据原文，未知待确认。
- 美术相关条目按内容概括具体画风或设计思路，表格列为“美术风格／设计思路”；技术资料留“—”，读取范围在状态与详情说明。
- 分享内容以原作者署名、原帖标题和直达链接为核心；没有完整配方也可记录有价值的分享及其信息缺口。
- 原文引用、转载摘录、社区反馈和本库整理备注分别标明。
- 无优质新增、部分访问受限或未完成时，在当天汇总记录真实状态，不虚构发现或平台覆盖。

## 每日汇总顺序

1. 日期、执行状态、检索类型与时间窗。
2. 当日值得阅读的社区分享和速查表。
3. 每条分享的作者、原文、要点、用途、公开配置与读取状态。
4. 固定来源的实际覆盖、未取得的信息与后续关注。
5. 当日另有主动搜索时，附加专题分节，避免替代广泛发现。
