# comfyui_collected-skills

一份持续更新的 **ComfyUI 生图社区每日发现与汇总库**。每天广泛查找社区分享的模型、工作流、提示词教程与实践经验，整理原作者分享要点和原文入口，希望让值得阅读的内容更容易被发现，也方便日后查阅与交流。

## 如何查阅

1. 打开[每日发现速查索引](每日检索可速查总结.md)，按日期或主题找感兴趣的内容。
2. 进入当天目录 `daily/YYYY-MM-DD/`，阅读其中的 `README.md` 汇总。
3. 通过条目旁的**原作者与原文直达链接**阅读完整教程、后续更新和讨论。
4. 需要深入时，再查看当天目录中按需补充的详细笔记或公开配置。

## 每日主要发现什么

- **模型与适配器分享**：后训练／特化模型、LoRA／LoKr、画师与风格组合、角色和场景资源。
- **工作流与配置分享**：ComfyUI 节点组合、自动提示与选型、多主体、构图、姿态／深度控制、采样和精修。
- **提示词与教程分享**：完整配方、写法组织、不同模型的推荐用法和适用条件。
- **实践经验与讨论**：作者示范、社区反馈、失败经验、版本差异与值得继续关注的新方法。

范围覆盖 Anima、Illustrious／IL、NoobAI 等已有路线，也持续发现其他模型家族、画风、用途和作者。收录依据是分享价值、可学习性和来源质量；不要求每条内容都解决某个已知问题，也不要求已有完整配方或本地对照实验。

## 固定来源

**百度贴吧的 stable diffusion／stablediffusion 吧、comfyui 吧，bilibili、Reddit、Hugging Face、GitHub，以及 Civitai 社区／论坛。**

逐平台查找社区文章、教程、模型／版本讨论、工作流、带配方的作品和经验分享；根据线索补充其他有效论坛与作者资料。记录实际检索和访问范围，尽量追溯到原作者原帖。

## 两类搜索怎样配合

| 类型 | 触发方式 | 过程与产出 |
|---|---|---|
| **每日固定的广泛分享帖子搜索（主流程）** | 每日执行，无具体差距要求 | 分平台发现 → 阅读和筛选社区分享 → 整理要点、用途与原文 → 保存当日汇总 → 更新索引 |
| **认识差距后的主动搜索（辅助专题）** | 已有明确问题、参考图或改进要求 | 明确差距 → 定向查询 → 寻找近目标示范 → 按需核对配方与自制对照 → 记录可参考方法 |

每日任务以第一类为主，无需先寻找本地不足。主动专题按需要另行开展；同日兼有两类内容时在当天汇总中分节标明，保持广泛发现独立覆盖。

## 更新与归档

已在 Codex 设置每天 **北京时间 09:10** 的搜索任务。调度由 Codex 自动化执行；本仓库保存规则与发现结果，克隆仓库不会自动创建该任务。

每次在 `daily/` 下建立当天的日期目录，以 `README.md` 汇总当日发现。同日重跑更新原目录；无优质新增或检索受限时，也如实记录实际覆盖和信息缺口。优先关注新增分享与实质更新，经典教程可补录并注明真实日期。

感谢社区作者公开分享模型、工具、教程、配方和示范作品。相关成果来自各位原作者；本库负责资料搜集、分类索引、摘要整理和学习笔记。
