## 收集什么

- **后训练模型与适配器**：Anima、Illustrious／IL、NoobAI 等路线的特化底模，以及角色、服装、场景、物件和风格 LoRA／LoKr。
- **工作流配置**：画师与条件混合、自动提示与资源选型、多主体、构图、姿态／深度约束、采样、VAE 与局部精修。
- **提示词和示范方法**：保留具体图像对应的完整正负提示、精确资源与有效设置，关注线条、光影、手绘感、服装准确性和角色保持。
- **适用边界与失败经验**：记录兼容性、未取得的配方、相反证据、迁移差异和撤回条件。

每条资料尽量回答：**解决什么问题、原教程在哪里、对应哪个版本、实际取得了哪些证据、下一步能参考什么。**

## 来源与检索方式

固定检索百度贴吧的 **stable diffusion／stablediffusion 吧、comfyui 吧**，以及 **bilibili、Reddit、Hugging Face、GitHub**；根据问题补充有效论坛与作者资料。

搜索按以下顺序推进：

**确定画面差距 → 分平台发现 → 观察近目标示范 → 追查同图配方 → 对照工作流与提示词 → 提炼迁移方法 → 归档与更新索引。**

论坛经验用于发现实例和失败线索，模型卡、节点文档与实现用于核对版本、输入和参数含义。推荐条目附原教程帖直达链接，必要时定位到楼层、视频时间点或文档章节。

## 每日更新与查阅

已在 Codex 设置每天 **北京时间 09:10** 的检索任务。调度由 Codex 自动化执行，仓库保存规范与结果；克隆本仓库不会自动创建该任务。

- 日报按 `daily/YYYY-MM-DD.md` 归档，同日补充更新原文件。
- [总索引](每日检索可速查总结.md)提供日期、主题资源入口及待补缺／待验证项。
- 每次优先搜索新增与实质更新，经典教程可补录并注明真实日期；无优质新增也记录实际覆盖与缺口。
- 当前已建立完整技能、检索规范、流程与维护指南；首份日报在任务首次成功归档后出现。

建议先按目标问题查索引，再打开日报中的原教程和配方。使用前核对模型版本、输入方式、运行器与资源条件，不能直接把旧配方套为新版本默认。

## 如何理解记录

同图实际参数、作者通用建议与工程拟补值分别标明。资料读取、加载／编译、原配方复跑、偏离复现、实际成图及用户认可也分别记录。

研究总结和迁移建议只表示相应证据支持的范围；具体效果以对应版本与执行记录为准。当前每日任务负责检索与资料整理，出图和实验按用户授权另行执行。

## 仓库结构

- `README.md`：项目说明和阅读导航。
- `每日检索可速查总结.md`：日期、主题索引与待处理问题。

- `AGENTS.md`：后续助手的维护入口。

## 维护方式

新增资料先核对原帖与版本，先写正文再补索引；相同来源与版本去重，结论更正保留日期和依据，失效链接标明状态并追查替代原始来源。具体规则见[资料库维护指南](docs/资料库维护指南.md)。

仓库保持轻量：保存研究记录与必要的小型配置，模型权重、运行环境和临时缓存另行管理。引用及配置保留原作者来源和已知使用条件。
