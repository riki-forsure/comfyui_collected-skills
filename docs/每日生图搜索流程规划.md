# 每日生图搜索流程规划

## 依据与目标

依据用户上传的 `image-workflow-research` 技能（SKILL.md 正文）与本项目既有检索规范，制定每日资料检索、示范拆解和方法提炼流程。技能引用的 `references/search-and-evidence.md`、`references/tutorial-learning.md` 未随附件提供，当前工作区未找到；本文不冒称已读取，后续取得时再补充。

目标是找到视觉接近目标、配置有据可查的示范，保存具体配方，并解释其对自制方案有何借鉴。不能只罗列模型、节点或教程标题。以下是搜索与整理规划，不代表已实施生成器优化或取得视觉收益。

## 第一步：明确当日要回答的问题

读取本规范、[检索规范与日报模板](检索规范与日报模板.md)、[总索引](../每日检索可速查总结.md)与近期日报，承接尚未解决的问题。

- 有用户最新参考图或明确任务时，拆成线条语言、人物画法、光影上色、构图尺度与结构关系，选出当前主要差距。
- 没有新增目标时，从待验证清单挑选主要问题；当前长期关注线条组织、阴影层次、手绘感、角色与服装保持、风格变化，以及自动选型和多主体控制。
- 先写清本次需要的是完整教程、配套提示词、资源、参数依据、故障反例，或其中几类。
- 保留原有输入边界：纯文字任务不能将使用参考像素、姿态／深度图或重绘的结果当作同条件效果；可以另列为需要额外输入的路线。
- 模型、画师、LoRA 数量、提示长度和采样值随目标选择，不预先固定为质量标准。

每期记录一句可回答的问题，例如：“哪类提示组织或条件混合，有证据能改善细线插画的阴影层次，同时保持角色服装？”

## 第二步：组合搜索，兼顾发现与补缺

每期开展三路搜索：

| 路线 | 目的 | 搜索方式 |
|---|---|---|
| 平台基础发现 | 发现新增模型、工作流、教程与失败反馈 | 逐一检查固定来源，结合近期日期、模型家族与发布／分享／教程关键词 |
| 主要问题专项 | 找视觉接近且任务难度相近的示范 | 目标特征＋问题＋方法／模型＋教程／示范／workflow／prompt 等组合 |
| 配方补缺与反证 | 补齐某张例图的设置，核查建议失效条件 | 作者／帖子标题／视频编号＋workflow／metadata／negative prompt／版本；另搜 failure、artifact、冲突、版本不兼容等 |

中文与英文交叉检索；必要时扩展日文。检索问题示例为词组组合，不应把所有词堆成一个过窄查询：

- `Anima 线条 阴影 教程 提示词`
- `Illustrious 多主体 角色服装 工作流`
- `NoobAI v-pred sampler workflow negative prompt`
- `ComfyUI artist mixing lineart shading workflow`
- `具体作者或资源名 + 同图配方缺失项`

在已确认的基座之外继续发现适用路线。先覆盖各平台，再深入有价值候选；平台受限则记录限制并寻找同作者可访问的原始资料。优先检查自上次成功检索以来的新增与实质变化；首期近 7 天，必要时回看近 30 天或经典教程并标明历史补录。

## 第三步：按平台寻找不同类型证据

| 来源 | 重点寻找 | 原始链接与定位要求 |
|---|---|---|
| stable diffusion 吧 | 后训练底模、画师／LoRA 配方、提示词、实际样图、失败案例与修正 | 具体主题帖；必要时记录楼层、附件和作者后续更正 |
| comfyui 吧 | 完整工作流、节点作用、结构控制、自动提示与多主体方案 | 具体主题帖与原工作流附件入口 |
| bilibili | 演示过程、提示词组织、节点连接、参数和前后对比 | BV 视频／专栏；记录关键时间点；简介、字幕、关键帧和实际观看分别标注 |
| Reddit | 实例配方、讨论中的适用条件、冲突、失败与作者答复 | 具体讨论及关键评论直达链接 |
| Hugging Face | 精确模型版本、训练／合并说明、示例配方、预测类型和兼容建议 | 具体模型卡、版本／revision 与示例文件 |
| GitHub | 节点真实作用、接口、版本变更、工作流示例、已知问题 | 对应文档／Release／工作流文件／Issue；必要时固定 commit |
| 补充论坛与作者资料 | 弥补案例、语言、模型或技术路线缺口 | 具体论坛、板块与原教程帖，注明选择理由 |

两个贴吧逐一检索。吧名入口沿用检索规范，并实际核对规范名称和重定向。搜索结果、首页和转载只是发现入口，最终条目尽量回到原教程帖。

## 第四步：先看视觉匹配，再决定深挖顺序

候选进入清单后，先检查能否实际看到例图，并比较：

- 线条：粗细变化、起收、轮廓和内部线、发束／衣褶组织。
- 人物：脸部、表情、手部、服装准确性、角色保持。
- 色面与光影：阴影层次、边缘、笔触、材质、手绘感。
- 构图与结构：景别、镜头、动作、主体数量、遮挡和关系难度。
- 输入与后处理：是否依赖参考像素、ControlNet、重绘、放大或人工修图。

视觉接近且任务难度相近的示范优先补齐资料；资料完整度用于判断可重放性，不能取代视觉匹配。只有文字宣传或不可见缩略图的候选标为“视觉未核”，可作线索，不能声称效果匹配。

通常精选 5–10 项只是篇幅参考，不设最低数量，不为凑数降低依据要求。允许保留视觉很有价值但配方尚缺的候选，明确缺口和补查方向。

## 第五步：将配置对应到同一张示范图

为入选示范保存配方记录，避免将作者通用推荐拼成某图实际设置：

| 字段组 | 保存内容 |
|---|---|
| 来源与例图 | 原教程帖链接、标题、作者、日期、例图直达链接／截图来源、视频时间点或楼层、图的身份标识 |
| 精确资源 | 底模版本／revision／可得哈希，编码器、VAE，LoRA／LoKr 名称版本及各自权重，画师条件与混合方式 |
| 提示与输入 | 字面完整正负提示词、触发词、输入图与用途、结构控制、分辨率、主体与镜头要求 |
| 运行与配置 | 前端／运行器、ComfyUI 与关键节点版本、原始 JSON／PNG 元数据链接、采样器／调度器／步数／CFG／种子及后处理 |
| 缺口与归属 | 每项值属于“该图实际设置”“作者通用推荐”还是“本地拟补值”；不明项写未取得，不推算补齐 |

保持字面正负提示与原配置可复制，不为了日报简短而改写原提示词。长配方可放在同一日报的折叠段或附录，摘要链接到对应条目；不强制为每个来源新建目录。示例图片及元数据无法取得时保留原入口并说明，不伪造完整配方。

记录实际读取范围：仅搜索摘要、已读正文、视频简介／字幕／关键帧／实际观看、配置文件读取、元数据读取、例图已观察。这些状态分别说明，不压成一个笼统的“已验证”。

## 第六步：拆解示范，与自制方案逐项对照

工作流配置与提示词组织分开比较。对有帮助的示范，至少回答“做了什么、依据是什么、可能服务什么职责、能迁移什么”。

| 比较对象 | 示范做法 | 自制方案现状／差异 | 教程或实现依据 | 可迁移优化 | 验证状态 |
|---|---|---|---|---|---|
| 工作流配置 | 节点、资源、连接、作用范围与有效参数 | 仅引用实际读到的对应版本；未取得写未取得 | 原帖、文档、实现位置 | 适用前提、改动组与保留条件 | 来源声称／机制假设／尚待复跑等 |
| 提示词组织 | 内容、角色、风格、镜头、区域归属与正负提示结构 | 保留字面提示比较，说明差异 | 同图配方及作者解释 | 可重用组织方法与失败边界 | 与配置验证状态分别记录 |

尚未取得当前自制方案时，只写“待对照”及所需文件／记录，不能凭历史聊天宣称当前生成器仍有某个缺陷。作者没有解释的职责标为机制假设，不把“画师 A 负责线条、B 负责阴影”或权重占比直接当作事实。

## 第七步：按主要差距提出迁移与验证方法

将改动分为三组：

- **运行推理组**：模型／编码器／VAE 兼容性、采样配置、运行器与节点差异。
- **风格组**：画师条件、LoRA／LoKr、混合方式、风格提示及其权重。
- **内容镜头组**：角色与服装、动作、多主体归属、镜头构图、结构控制及其输入。

每条建议写清：遇到什么现象 → 优先改哪组条件 → 必须保留什么 → 预期观察什么 → 什么情况下撤回。先保留有效条件，按主要差距选改动；如果同时改变多个组，只评价整套方案，不单项归因。

本每日任务交付资料与方法，不自行启动生图、安装节点或批量实验。以后用户授权效果实验时：
1. 先以同版本原教程配方复跑，已有同版本真实复跑可复用。
2. 缺件、替代与迁移偏离逐一记录，再安排接入自制方案的实验。
3. 原配方复跑与迁移实验分别保存完整请求、配置、输出、观察及反馈。
4. 阅读、编译、加载、实际成图、人工认可分别记录；用户认可只覆盖明确认可的范围。
5. 单例不推广为跨人物、景别、主体数或种子的稳定规律；直接复用须读取冻结执行记录。

## 第八步：保存可速查结论，并承接下次检索

沿用已有归档结构：

- `daily/YYYY-MM-DD.md`：问题、来源覆盖、候选、具体配方、学习对照、下一步方法及各自效果状态。
- `每日检索可速查总结.md`：日期目录、按问题／用途和资源检索的入口、待补缺与待验证清单。
- `docs/检索规范与日报模板.md`：通用选择、调整与判断规则；个图参数和用户反馈留在对应日报／案例记录，不把一次有效的数值变成通用硬规则。

保存前检查引用与结论是否对应、同图配方是否混入通用推荐、视觉判断是否真的看过图、是否误称已复跑或已实现。此为资料整理自查，不新增运行测试或派发子代理。

日报开头简短呈现：
1. 今天解决或推进了什么问题。
2. 最值得看的近目标示范及原教程链接。
3. 可迁移的方法和主要证据缺口。

按规范链接＋版本／实质变化去重；单纯转载不算新发现。没有优质新增也保存实际检索覆盖与缺口。各固定平台标明实际完成状态。原帖不可访问时说明，不能据此推断没有更新或教程无效。

## 每期完成标准

- 有明确问题，已记录固定平台与两个吧的实际覆盖或访问限制。
- 推荐与结论旁有可点击原教程帖／原始资料链接。
- 视觉匹配判断、同图配方、通用推荐和本地拟补值能够分辨。
- 有价值的示范包含方法提炼；可取得自制方案时有版本明确的对照，取不到时标明待对照。
- 下一步建议含适用条件、保留项、观察指标和撤回条件；证据不足不宣称稳定收益。
- 日报和总索引已保存到项目，或明确交付未能保存的内容及原因。
