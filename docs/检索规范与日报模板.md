# 生图资源检索规范与日报模板

具体执行顺序见[每日生图搜索流程规划](每日生图搜索流程规划.md)，按问题发现、近目标示范、同图配方、学习对照和迁移方法组织检索。完整依据：[技能正文](../skills/image-workflow-research/SKILL.md)、[检索与证据规则](../skills/image-workflow-research/references/search-and-evidence.md)、[示范学习与方法提炼](../skills/image-workflow-research/references/tutorial-learning.md)。执行前读取三份文件及最新规划。

## 项目目标与范围

从生图社区与作者原始资料中筛选可用于 ComfyUI 插画工作流的优秀后训练模型、工作流配置和提示词教程，沉淀为可复查、可复现的参考资料。本文依据“生图工作流”项目既有需求归纳；后续以用户最新要求及本仓库新增说明为准。

重点覆盖：
- 后训练与衍生底模：Anima、Illustrious／IL、NoobAI（分别核对 epsilon 与 v-pred）及适用于目标的其他路线；区分微调、合并、烘焙适配器及作者未披露的训练方式。
- 适配器与画风：角色、服装、场景、物件、风格 LoRA／LoKr；画师标签串、条件混合、注意力混合、分层与分阶段权重、区域作用和兼容性。
- 工作流：一句话自动提示词与资源规划，固定或切换画风，多主体与关系绑定，构图、姿态骨架、深度图及其他结构约束，采样、VAE、局部精修和原生输出。
- 教程与问题解决：模型专用提示词、标签／自然语言策略、触发词、正负面词、权重，线条粗细与组织、阴影层次、手绘质感、服装准确性、角色保持及风格跨度。

## 检索方法

1. 先读本规范、总索引与近期日报，提取未解决问题，避免重复收录。检索围绕真实生成目标与已知工作流问题展开。
2. 使用中文与英文关键词交叉检索；必要时加入日文关键词。模型、工作流、教程三类均应覆盖。
3. 固定检索平台包括百度贴吧（优先用户指定的吧）、bilibili／B站、Reddit、Hugging Face 和 GitHub。按主题补充确有有效信息的论坛、ComfyUI 社区、Civitai、YouTube 和作者帖子。每天记录各固定平台的实际检索情况，不以单个平台替代其余平台；未访问或受限应明确标注。来源核验优先作者模型卡／仓库／发布页与官方文档，以及带参数、工作流或可核查对比的原教程帖和讨论。
4. 优先核查自上次成功检索以来的新增与更新，首次主要看近 7 天；必要时回溯近 30 天或补充经典教程，标明实际发布日期与“历史补录”，不要将旧内容说成新品。
5. 打开原始页面，记录作者、精确版本、发布时间／更新时间和原始 URL。搜索摘要、视频简介、转述和仅文件信息不得当作已读正文。
6. 先观察例图与目标在线条、人物、色面光影、构图和任务难度上的匹配程度，再按配方完整度和兼容性安排补查与后续实验优先级；未实际看图标为视觉未核。资源齐全、热度、节点复杂、提示词长短、步数或分辨率不单独证明质量。通常精选 5–10 项仅作篇幅参考，不足不凑数。
7. 同一资源多处转载合并记录。版本或方法有实质更新时写清变化，并回链旧条目；同日重跑更新原日报，不重复建档。
8. 没有优质新增也要保存当日覆盖范围、结果与缺口。访问失败如实记载，使用仍可访问的来源完成检索。
9. 本任务只研究与归档。没有用户另行要求时，不下载大模型、不安装节点、不启动 ComfyUI 或提交出图。

## 平台与贴吧名单

- 固定平台：百度贴吧、bilibili、Reddit、Hugging Face、GitHub。
- 用户指定的贴吧固定名单（2026-10-30 确认）：
  - **stable diffusion 吧**：[按指定吧名访问](https://tieba.baidu.com/f?kw=stable%20diffusion)。初始关键词：后训练模型、底模、LoRA、画师串、提示词、采样、线条、阴影、教程、工作流。
  - **comfyui 吧**：[按指定吧名访问](https://tieba.baidu.com/f?kw=comfyui)。初始关键词：工作流分享、节点、ControlNet、姿态、深度图、自动提示词、多主体、参数、教程。
- 每次逐一检索这两个吧，结合模型名、任务与问题动态扩展关键词。吧入口按用户提供的名称构造，实际检索时核对平台显示的规范吧名与重定向；若入口失效，通过平台或公开搜索定位并记录，不能静默跳过。
- 在日报中分别记录两个吧的实际检索结果、原主题帖直达链接与访问状态；未读正文、无命中或访问失败均如实标明。
- 补充论坛按信息质量动态选择，记录具体论坛／板块及原帖，不仅给平台首页或搜索页。

## 证据与参数要求

- 项目维护、日报、资源索引与教程整理均应贴出可点击的原教程帖链接，并将支持具体配置或结论的链接放在对应条目旁。保留标题、作者、日期、平台和原始直达 URL，不仅给首页、搜索结果或二手摘要。贴吧优先具体主题帖，B站给具体视频／专栏，Reddit 给具体讨论／必要评论，GitHub 给对应 README／文档／Release，Hugging Face 给具体模型卡／版本。可定位时补充楼层、视频时间点或文档章节。
- 转载内容尽量回溯原教程，分别保留发现入口与原始来源。原帖不可访问或已删除时，保留已核实的原始链接并标明访问状态；仅有转载或摘要时说明证据限制，不编造来源。
- 同一示范图对应保存精确资源、字面完整正负提示、输入、有效配置、运行器／节点版本及可得元数据。分别标注“该图实际设置”“作者通用推荐”“本地拟补值”；不得混成一份假称实际使用的配方。记录关闭／未连接项与隐式默认值；哈希注明算法和覆盖范围，不跨算法比前缀；能加载不等于完全兼容。
- 工作流从最终输出反查实际生效分支与补丁顺序；API 请求不冒称节点图。提示词区分作者原词、UI 显示、编译器补词、分支及实际编码文本，未捕获的部分标未知。分开解释提示权重、画师混合系数、LoRA MODEL／CLIP 和结构强度。
- 工作流配置与提示词组织分别学习，记录“示范做法→自制差异→依据→可迁移优化→验证状态”。自制版本未取得时写待对照；原配方复跑与接入实验分别记录。
- 阅读、编译、加载成功、实际成图与用户认可分别记录；来源声称、机制假设、本地观察与人工认可不能混用。本任务未实际出图的内容不得标为实测，保存方案不等于生成器已实现或视觉收益已验证。
- 下一步建议按运行推理、风格、内容镜头三组组织，写清适用现象、改动组、必须保留的条件、预期观察与撤回条件。多组同时变化只评价整套方案，不单项归因。
- 模型记录基座家族、精确版本／预测类型、编码器、VAE、推荐采样器／调度器／步数／CFG／分辨率、触发词与适配器权重；作者未给出的值写“未说明”，自行建议写“工程试用值”及依据。
- 工作流记录原始 JSON／PNG 下载链接、必要节点及版本、模型依赖、关键节点连接／设置、显存要求（来源有说明才填）、适用任务与已知限制。
- 教程保留适用模型、核心步骤、可复制提示词或参数示例、失败条件及原始依据。不能将一种模型的规则直接迁移为其他模型的通用要求。
- 看例图时关注线条、阴影、笔触、角色／服装、构图及内容保持；区分原生输出与放大、修图结果。
- 下载页和许可证有明确内容时记录；未知写未知。不得编造作者参数、链接、节点能力或验证结论。

## 归档约定

- 日报：`daily/YYYY-MM-DD.md`，日期与检索时间均用北京时间（Asia/Shanghai）。
- 总索引：仓库根目录 `每日检索可速查总结.md`。同时维护日期目录、按主题资源索引和待验证清单。
- 规范：本文。每日检索开始时重新读取，吸收项目范围更新。
- 成功写入仓库后再报告保存成功，提供日报与总索引链接。写入失败时仍交付完整日报内容并明确说明未归档。

## 条目详解

### 资源名称与版本

- 作者；发布／更新时间；本次是新增、更新还是历史补录。
- 解决什么问题、适用与不适用场景。
- 模型／节点依赖和兼容性。
- 作者推荐参数、触发词；未知项及待验证项。
- 工作流或提示词的可复制示例（有可靠来源才提供）。
- 例图或对比说明；是否含后处理；推荐依据。
- 原教程帖／原始来源直达链接、标题、作者、平台、日期与正文读取状态；可定位时补充楼层／时间点／章节。
- 同图配方：例图身份与来源、精确资源、字面完整正负提示、输入及后处理、运行器／节点版本、元数据；区分该图实值／通用推荐／本地拟补值及缺口。
- 视觉匹配：线条、人物、光影色面、构图与任务难度；未实际观察例图应注明。
- 与已有条目关系、下一步最小验证方法。

## 配方状态与证据边界

按真实情况记录“已按原配方复跑／有偏离的复现／仅采用局部建议／仅读取／缺件待补”；阅读来源另列正文、完整工作流、原生例图、视频画面／字幕及范围、简介、评论及范围、摘要、未取得。缺失参数与私人配方保持未知。

已授权的后续原样复跑保留字面提示顺序、重复、拼写、正负冲突、原资源、前端版本、seed、尺寸与 RNG；偏离单列。改编失败不证明原教程无效，教程有效不保证接入收益。人工认可需对应原话、范围、实际图、执行配置与资源版本；助手评分与局部表扬不等于整体认可。每日任务不会因此自动启动实验。

## 项目可用结论与下一步方法

区分可直接参考的配置、需要适配的方案和待实测假设；列出优先验证的 1–3 项。每项说明“什么现象→改哪组条件→保留什么→观察什么→何时撤回”，遵守文字／参考图／结构控制等原输入边界。

原配方与迁移方案的状态分别记录：来源声称、资料读取、机制假设、编译／加载、实际成图、用户明确认可；无相应记录写未执行／未取得。本日报任务仅研究归档，不自动开展上述出图实验。
